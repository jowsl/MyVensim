Detailed Description

Friend test class that accesses SystemImpl internals.

Declared as a friend in SystemImpl. This class contains static methods that execute the tests by directly reading and writing to the protected 'name' and 'value' fields. This guarantees that each test strictly validates only one method at a time, avoiding cross-contamination from other public methods (like getters or setters) during setup or assertions.
