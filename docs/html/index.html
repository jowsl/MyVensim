MyVensim - System Dynamics Simulator

Introduction

MyVensim is a generic C++ API designed to simulate System Dynamics models, closely mirroring behaviors found in professional tools like Vensim. It allows users to model complex dynamic structures and run continuous numerical integration.

Core Architecture

The framework is built upon three fundamental structural blocks:

  • System: An interface representing stocks (such as material, population, or energy) that store values over time.
  • Flow: An interface representing the transfer pathways and algebraic differential equations connecting the systems.
  • Model: An interface representing the orchestration engine responsible for running the simulation timeline and ensuring synchronized updates.
