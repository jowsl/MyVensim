Detailed Description

Friend test class that accesses ModelImpl internals.

Declared as a friend in ModelImpl. It manages testing by directly inspecting and modifying the protected 'systems' and 'flows' vectors. This guarantees no hidden dependencies on add(), begin(), or end() while testing core functionalities like execute() or the assignment operators.
